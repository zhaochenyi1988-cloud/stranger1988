使用、关闭恢复和备份说明

将 residential_lab_v04.html 保存到 Windows 固定文件夹，用当前版本 Edge 或 Chrome 的常规窗口打开。无需解压、安装软件或联网。再次打开同一文件时从浏览器数据库恢复。

顶部“已保存”表示本机数据库已经提交；“保存失败”时尚未保存的内容会保留，不能当成保存成功。关闭前等待已保存。隐私窗口、清理浏览器数据、换浏览器或文件位置可能改变存储环境。

程序HTML不包含项目和附件。换电脑请“导出完整项目包”，在新电脑的此页面选择“导入项目包”。备份ZIP由页面读取，不需要用浏览器或解压软件打开ZIP。原件缺失会明确提示。

旧版 V0.2 JSON 可以作为新项目迁移，原文件不覆盖；原JSON没有原件的内容无法凭空恢复。图纸和照片原字节归档，预览独立；不支持识别的类型仍保留原件。本版本支持外部模型结果导入，不在页面内调用模型；没有收费API、CAD绘图或PPT生成。

“保存程序HTML”下载干净程序，不包含已录入项目内容。原V0.3服务器地址下的数据库和此文件模式属于不同存储环境，应导出完整包后导入。

如浏览器限制本地文件数据库，页面会报告失败并停用写入，不用内存假装已保存。可在允许本机数据库的浏览器中使用，或使用原V0.3本机启动方式后导入备份。Windows文件模式尚未实机验证。

V0.4 操作说明、字段字典与接口约定

使用与迁移

  1. 将 residential_lab_v04.html 下载到 Windows 固定文件夹，使用新版 Edge / Chrome 的常规窗口打开。无需安装软件或联网。首次为独立空白资料库，不内置客户项目。
  2. 旧版先导出完整项目包，再在新版导入；若能检测到旧资料库，也可逐项目复制。新版使用 residential-library-v4-portable 数据库，旧库不改写。不要清理旧浏览器资料，直到核对新版完整备份。
  3. 新建项目，登记总览、空间、条件、需求及方案。上传时选资料类别、细分类别、楼层、空间与版本；08 页面用于分类查找，原有七个板块保留。
  4. 等待“已保存”后关闭。项目、原件与未完成编辑输入保存在浏览器 IndexedDB；程序 HTML 不包含项目数据。换浏览器、换地址、换电脑、移动文件或清理浏览器资料可能改变存储环境，必须靠完整项目包恢复。
  5. 09 页面选择任务与资料范围，方案比较需选择两个版本。导出输入包和 JSON 模板，按需交由外部模型分析。此页面没有网络模型调用，不发送客户资料；外部工具是否上传由你自行决定。
  6. 导入按接口模板生成的结果，核验引用后保存原文。逐条审核，选择认可、部分认可或不认可，填写审核人、依据及修订判断。反复审核追加历史，原始分析不覆盖。
  7. 有效审核可提取候选 Skill。补充适用条件、依据、动作和例外；人工确认仍需跨项目验证。导出 JSON / Markdown 仅为维护候选规则，不会发布或安装正式 Skill。
  8. 定期“导出完整项目包”。ZIP 由应用直接导入，不必解压。备份包含原件、预览、输入快照、结果原文、纠偏、候选规则及草稿；必须检查下载文件存在。Excel 只交换业务资料，不是完整备份。

外部分析接口

请求：residential-analysis-request / contractVersion 1.0。输入包含 request.json、result-template.json、附件清单及可用原件；单独输入 JSON 只含结构化资料与附件路径，视觉分析仍需原件。结果：residential-analysis-result / 1.0，origin 为 external-model，含 resultId、requestId、projectId、inputRevision、model（provider/name/version）、generatedAt 和 findings。每条 finding 含 id、type（structure / needs_match / missing_risks / version_compare）、problem、basis、risk、suggestion、toVerify、evidenceIds。只可引用该输入包登记的 ID。

未来本机后端可实现同一请求 / 结果协议，服务端保存密钥；不得在 HTML 中配置密钥。本版不内置网络调用、密钥、付费 API 或自动公开发布。

可靠性与已知限制

自动保存以 IndexedDB 事务提交为准；失败保持未保存状态和草稿，已有事务记录保留。单文件上限100MB、项目包500MB、结构化模型结果2MB；备份在内存中打包，不适合超大资料库。模型结果结构正确不能证明其专业判断正确，需人工审核。图像预览只支持 PNG/JPEG/WebP，PDF/DWG/DXF 等只归档原件，不识别承重、几何或CAD。

资料快照变化会标记分析可能过期，包括修改来源、附件分类、核验状态和未完成资料草稿；审核及候选规则更新不会单独使资料分析过期。规则库跨项目验证、正式Skill维护、模型实际调用、效果图、CAD、PPT不在本版本。

# AI住宅设计实验台 V0.4 变更与验收报告

日期：2026-10-13（用户时区 Asia/Shanghai）

交付保持空白项目。用户同意先验证功能框架，模拟资料仅存在于隔离的测试环境；没有使用真实客户资料。

## 检查结论

已复现：V0.3.1 可以录入、持久保存原件及未完成草稿并导出完整包。其AI结果仅为预留字段，未调用模型。
代码风险及本轮修复：跨项目附件ID冲突可能覆盖二进制原件；重复导入需要增加分析、纠偏及候选规则内部关联映射；附件重试后的展示状态需要刷新。
暂未验证：Windows浏览器直接双击本地HTML。云端浏览器返回 net::ERR_BLOCKED_BY_ADMINISTRATOR；未绕过该限制。

- 无效模型引用指出具体字段，原有分析保留，粘贴原文恢复
- 篡改或删除原始判断、纠偏历史的写入被拒绝，数据库原文保留
- 旧 V0.2 JSON 与 V0.3 项目包均可迁移，原件缺失明确列出
- 本地规则检查实际执行，未调用模型的状态准确
- Excel业务导出和导入保留附件分类索引并声明非完整备份

### extras：5项

- 项目包写入中断时事务回滚，原项目可继续编辑
- 单个附件写入失败时先前附件保留，重试后状态与原件一致
- 分析原文与判断写入失败不半入库，原文草稿保留且可重新导入
- 跨项目附件ID碰撞不能覆盖已有二进制原件
- 元数据损坏即使重新打包也拒绝导入，避免失去原文与分析关联
