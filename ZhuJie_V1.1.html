    筑界 V1.1 · 使用与交付
    1. 追加 1～12 张同一空间现场照片，每张原件 ≤20 MB、20 百万像素、最长边 ≤8192 px。原图总量 ≤120 MB，全部图片资产 ≤160 MB。
    2. 左侧点击切换编辑视角；“作为主图”只设置本次输出目标。视角页填写名称、内容、同空间确认、用途和可核实的相机参数。
    3. 矩形拖动绘制；多边形逐点单击，Enter 完成。选择后拖动区域 / 顶点可修改，Ctrl+Z / Ctrl+Y 撤销 / 重做。未完成轮廓需先完成或取消，才能切换或导出。
    4. 选中区域，在对象页新建真实对象或关联已有对象。同一对象在不同照片中只需维护一套改造节点；程序不自动识别或合并。
    5. 实际保留的地面、石材、家具等应分别建对象并标明保留边界。将需要改造的对象设为“按节点改造”，创建节点，明确前后状态、保留条件与允许范围，再勾选“参与本次生成”。
    6. 节点可上传最多 3 张目标样式图。只有勾选“用于本次生成”的参考图进入 AI 包，现场视角和样式图分角色记录。
    7. 空间 / 光页按实测资料填写。未知留空存 null；真实 0° 是北向，不是未知。方位均为真北 0°、东 90°、南 180°、西 270°，顺时针。镜头方向与窗户外法线是不同字段。建筑基准轴不再次叠加到已按真北输入的角度。
    8. 理论太阳方向使用经纬度、明确时区偏移、日期与本地时间离线计算；缺北向 / 窗向依据则降级为漫射光，不推断遮挡、玻璃或光斑。色温用于视觉目标，不是照度 / 显指仿真。
    9. 顶部保存完整“项目备份 ZIP”，包括全部有效原件和可编辑数据；确认电脑里存在备份后再点击落盘确认。关闭后用“打开项目备份”恢复。AI 包不是项目备份。
    10. 底部选择唯一主图、最多 3 张相关现场补图，并人工核对全局补充文字。通过检查后导出 AI 包，交给支持图像编辑的 ChatGPT。
    迁移：打开正常的 V1.0 ZIP 会先做完整校验，再只读迁移。保留项目 ID、名称、意图、区域 ID / code / 规则 / 坐标与原件；每个旧区域独立建立待确认对象，不自动合并。未经审核的改造节点默认不启用。
    删除与撤销：视角删除只移除该图标注；对象删除会明确列出视角 / 节点 / 参考图引用并一致处理。备份只含当前有效资源；会话撤销可暂留图片，最多 100 步 / 200 MB 资源预算，以先到为准。跨项目打开不保留撤销。
    存储与失败：编辑数据在页面内存。正式可恢复资料是独立 ZIP；程序不改写原图或旧备份。导入先校验、准备资源，再整体切换；失败保留当前项目。浏览器下载触发不能证明落盘，关闭提示也不能防断电。
    边界：建筑结构改动可记录独立授权与审核，仍不能进入 V1.1 普通 AI 图像改造包。程序不保证图像生成遵从，也不自动生成效果图或判定结构安全。推荐桌面新版 Edge / Chrome；离线无 CDN、无后台和图像 API。
